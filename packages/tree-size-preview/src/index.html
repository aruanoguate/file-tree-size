Tree Size for VS Code
Free extensions to visualize file weight — JSON & XML

Open-Source VS Code Extensions

Find what's bloating your JSON & XML files.

Ever opened a multi-megabyte config, API response, or data export and wondered where all those bytes are hiding? Tree Size gives you the answer instantly — an interactive, ranked breakdown of every key and element by size, right inside VS Code.

Free and open-source. Processing is local, and your file contents are not uploaded by the extension. Built as a solo project by Alvaro Enrique Ruano. Try the live preview below or install directly from the marketplace.

Available for JSON and XML

Each extension is purpose-built for its format. Preview them live in your browser, or install from the VS Marketplace and Open VSX.

JSON Tree Size

See which keys, arrays, and nested objects weigh the most. Drill down the tree, spot the heaviest branches, and jump to the exact line in your source.
